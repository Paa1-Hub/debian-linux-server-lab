# Debian Linux Server Administration Lab

## Project Overview

This repository documents my hands-on journey learning Linux system administration using Debian Linux Server and VMware Workstation Pro.

The purpose of this project is to develop practical Linux skills through installation, configuration, administration, troubleshooting, and security exercises.

This lab supports my studies in LPI Linux Essentials and my long-term development in IT infrastructure, Linux system administration, and cybersecurity.

## Lab Environment

| Component | Configuration |
|---|---|
| Host Operating System | Windows 11 |

## Learning Objectives

- Understand Linux operating system fundamentals.
- Install and configure a Debian Linux server.
- Develop Linux command-line proficiency.
- Manage users, groups, files, and permissions.
- Configure Linux networking and SSH.
- Manage software packages and system services.
- Practice Linux security and troubleshooting.
- Develop Bash scripting and automation skills.
